      Two spoken questions — ask after marking, never before

      1. For part F: “In this story, did anyone give anyone anything?” — the right answer is no: in a comparing problem nobody loses anything, both sides still have everything. Answering this is what separates separating from comparing; getting the arithmetic right does not, because both stories reduce to the same subtraction.

      2. For part G: “Which addition told you that ?” — pointing at the addition that was given is recall; counting on fingers and then answering is recalculating. Same answer, two different things.
